# TipSync

**Lip sync sells the show. TipSync saves the business.**

Mobile-first gig and cast ledger for Texas drag hosts who collect first and pay the cast on their own apps. TipSync **tracks**; it does not process payments.

**Repository:** https://github.com/VesperRun/TipSync

## App (PWA scaffold)

```powershell
cd app
npm install
npm run dev
```

Open http://localhost:3000 — mobile viewport recommended. Static mock gigs (Dallas / Houston) until Phase 1 (auth + database).
